# Chapter 3 candidate validation — Unity integration checklist

The draft levels in Assets/_Game/Data/Levels/Chapter3_Drafts are **not yet part of the published campaign**. The original 40 .asset files, Prototype.unity, save schema, ChapterSelect, Perfect verification and MORA are unchanged.

1. Open the project using Unity 6.3 LTS after updating the content branch.
2. Menu: SHIFT > Chapter 3 > Validate Draft Levels 41-50.
3. Run Editor Test Runner: Chapter3DraftTests. All ten must pass before anyone calls the boards certified.
4. Review each draft board in an **isolated preview**, ensuring a distinct reasoning challenge and a meaningful payoff. Current levels are working prototypes derived from creatively modified existing mechanic structures; they are not final art-direction-locked original puzzles.
5. Rebalance or replace bland boards, including difficulty ramp, visible teaching moments and clear failures. Keep separate puzzles and documented player feedback before the campaign is extended.
6. Only after validation: add Level41-60 wiring, chapter identity, ending handoff, safe-save migration and MORA growth milestones. Do not edit Levels 1-40.

Offline independent simulator reproduced the shortest routes of Levels 35–40 and found shortest routes of 5,6,5,5,7,6,6,7,7,8 for these **candidate** boards. This is supporting evidence only, not a Unity build/certification or user playtest.
